这是一个采用原装 Google Material Design 3 风格精心打造的极简、沉浸式 Markdown 编辑器。

## 🎨 官方原装 Material Design 3 风格

我们严格遵循谷歌官方最新 Material 3 设计规范，完美适配官方组件库，绝无任何第三方框架带来的 UI 错位和排版瑕疵。

### 组件演示

- **文本输入**：右侧顶栏的文档名称输入框以及所有弹窗的输入框，均支持官方 M3 Outlined Text Field 原生交互。
- **对话框**：添加用户和推送到博客弹窗使用原生 HTML5 `<md-dialog>` 影子 DOM 渲染，安全隔离，支持 Escape 键与外侧点击自动关闭。
- **控制按钮**：所有图标与文字按钮均配备原生水波纹动画（M3 Ripple）。

## 🔒 智能两步式 GitHub 博客授权发布引擎

为了给博客写作者提供最极致的发布流程，我们移除了所有繁琐配置：

1. **第一步（Token）**：只需复制并粘贴您的 GitHub Personal Access Token。
2. **第二步（选择仓库）**：系统会自动查询您的 GitHub API，拉取您的头像和**所有包含博客的仓库**（Hugo, Hexo 等），您只需一键点选即可！
3. **博客路径自动解析**：
   - 如果选择 **Hugo** 框架，路径自动设定为：`content/posts/YYYY-MM-DD-title.md`
   - 如果选择 **Hexo** 框架，路径自动设定为：`source/_posts/YYYY-MM-DD-title.md`
   - 如果选择 **直接提交**，还可以激活可视化文件浏览器，在 GitHub 线上仓库目录中直接点选已有文件或在线创建新文件！

## 💻 键盘快捷键 & 便捷功能

- **专注模式**：按 `Ctrl + \` 隐藏工具栏和预览，进入极致专注的写作空间。
- **加粗**：`Ctrl + B`
- **斜体**：`Ctrl + I`
- **链接**：`Ctrl + K`
- **一键导出**：支持导出 Markdown (.md)、静态 HTML (.html) 以及复制渲染后的 HTML。
